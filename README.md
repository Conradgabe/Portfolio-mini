# Gabriel Isuekebho — Portfolio (mini)

A clean, classic portfolio site for a backend developer. Single page, structured
sections: About, Skills, Experience, Projects, and Contact.

- **Stack:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4
- **Design:** classic professional (navy + slate grey on white), responsive, accessible

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

Content lives in `lib/content.ts`.
